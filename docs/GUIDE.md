# 使用指南

> 适用版本：1.20.0 · 本地入口 `http://127.0.0.1:5173`

这份指南按第一次使用的顺序写：关闭演示 → 接入真实 Agent → 接入 AI → 创建任务 → 看执行与审批 → 完成后开启下一轮。

> **最快入口：`Cmd/Ctrl + K`** 打开命令面板，可直接搜索任务、Agent 或操作（新建任务、Boss Inbox、接入 Agent、设置、主题等）。

创建任务时可以先点 **快速模板**（电商运营 / 内容增长 / 产品发布 / 故障复盘），自动填好目标、验收、优先级和 Token 上限。Boss Inbox 支持勾选多条花费/登录/授权审批批量处理；对话右上角的 **⌕** 可以搜索当前完整对话记录。左侧顶部「群消息」和「沟通」都能打开双栏聊天工作台：左边搜索/过滤会话，未读角标、固定、静音、重命名和删除都在会话菜单里；右边支持 Markdown/代码、复制、引用回复、附件、拖放/粘贴上传、`@` 成员建议、草稿、详情与文件，以及 `Cmd/Ctrl+F` 消息搜索。顶部「群消息」位于「工作」上方并带未读角标；「沟通」浮层里的「已有群组」列出已建群组和任务群，点一下直接进入；「新建群组」不再放在「创建」里。Mission Control 里的群组/私聊和「聊天工作台」按钮也进入同一个工作台。私聊和群聊发送后，Agent 会通过本机 AI 生成回复，期间显示「Agent 正在输入…」；Mission Control 和聊天工作台都支持。没有可用模型时会明确回退提示，不会静默。任务进度、审批和自动执行状态通过本机 SSE 实时推送，通常不到 1 秒刷新。

---

## 1. 关闭演示 / 预设

有三种入口，任选一种：

1. **右上角「关闭演示」按钮**（最快）  
   点击后变成「恢复演示」，再点恢复。
2. **左侧「设置」→「演示与预设」**
3. **工具 →「演示与预设」**
4. **右上角「指南」→ 指南弹窗里的「关闭演示」**

关闭后：

- 暂停办公室模拟
- 隐藏 6 个本地预设角色、剧本任务、模拟看板和模拟消息流
- 停止并移除演示 Agent
- 首页切换为 **REAL OPS**
- Mission Control 的推荐和新建任务只使用真实外部 Agent

不会删除：

- 真实外部 Agent
- 真实任务、汇报、交付物
- 上传文件
- 审批记录

恢复：再点一次「恢复演示」。  
关闭演示只影响本地浏览器；真实数据仍在本机 `~/.agent-office/`。

关闭演示后会**直接进入真实工作区**，不再先弹一个全屏 REAL OPS 面板。外部 Agent 会以像素角色出现在工位上：执行真实任务的 Agent 会高亮、显示任务气泡和进度条，其余 Agent 会在办公室走动；顶部统计、团队士气和右侧活动流切换为真实数据。左下角「真实运营模式」小卡片可以关闭，也可打开任务中心；需要查看完整说明时点顶部 **真实模式面板**。

## 2. 接入真实 Agent

入口：**人脉 → 添加外部 Agent**。

支持：

- Codex / Codex Desktop
- Claude / Claude Code
- WorkBuddy
- 豆包 Doubao
- DeepSeek
- Gemini
- Kimi
- Qwen
- Ollama
- 自定义 HTTP Agent / MCP

可以自动识别品牌 Logo，也可以手动设置职务、头像、颜色和技能。连接后，外部 Agent 会出现在 TEAM 面板，并可被任务推荐选中。

### 关闭演示后怎么测试真实场景

- 外部 Agent 显示「离线」只表示它没有上报心跳，不代表不能创建任务。
- 在本机 AI 可用时，自动执行会按分配给外部 Agent 的身份完成任务；**离线也能跑**。
- 如果要让外部进程真正执行，需要启动对应连接器（Codex / WorkBuddy 等）或配置 endpoint + 心跳。
- REAL OPS 右侧/封面的真实任务可以直接点开继续；自动执行中断的任务会显示错误原因，打开后可重试。
- 需要从零开始时，点封面 **创建真实任务**，填写目标、验收和 Token 上限即可。

## 3. 3 步接入 AI

入口：**工具 → AI 模型服务 → 3 步接入 AI**。

1. **选服务**：豆包、DeepSeek、WorkBuddy、Gemini、Claude、OpenAI、Kimi、Qwen、Ollama。
2. **填连接**：复用本机环境变量，或粘贴 API Key；高级设置可改模型和接口地址。
3. **测试并启用**：bridge 发起一次真实最小调用，通过后才保存。

密钥只写入本机 `~/.agent-office/providers.json`（权限 `0600`），不会进入浏览器存储、任务记录、日志或仓库。

## 4. 创建任务

入口：**创建 → 任务管理**，或 Mission Control 的 **+ 新建任务**。

填写：

- 任务标题
- 目标描述
- 验收标准
- 优先级、预算、截止日期
- **Token 上限**（可选；0 / 留空表示不限制）
- 上传文档或图片（会进入 AI 上下文）
- 团队：自动推荐，也可以手动勾选
- 每个子任务的执行 Agent
- **创建后全自动执行**（讨论 → 分配 → 执行 → 汇报）

规则：

- 只有 **花费、拍板、扫码登录、授权** 四类事项会暂停等你审批。
- 技术方案、架构、工具、排期、测试、文案和设计取舍由 Agent 讨论解决。
- 每个成员必须有主任务或待命巡检任务，不允许空岗。
- 任务汇报必须包含：已完成、下一步、风险、解决方案、证据。

---

## 5. 执行、审批与停止

任务顶部有常驻命令条：

```text
讨论 → 审批 → 执行 → 汇报
下一步 · 需要你操作 / 无需操作
```

- 讨论完成但未执行：显示 **开始执行 N 个任务**
- 没有计划：显示 **讨论并执行**
- 正在执行：显示当前任务和 **停止**
- 有老板门禁：显示 **处理审批**
- 全部完成：显示 **开启下一轮 / 查看复盘 / 查看计划**

首页办公室会显示：

- **MISSION LIVE** HUD
- 当前任务、执行 Agent、进度
- 当前任务已运行时间
- 直接 **停止** 按钮
- 外部 Agent 热桌卡和本地角色任务气泡

Token 上限达到时会停止自动执行；在任务评估里调整上限后可继续。

### 任务列表与人工干预

- 任务页顶部的 Agent 过滤会同时显示该 Agent 的完成数和加权进度；勾选任务可批量接受评审或标记阻塞。
- 评审中的任务可以直接 **通过并完成**、**退回重做**；未完成的任务可以 **标记阻塞**、**改派** 或 **编辑标题 / 说明 / 验收 / 优先级**。
- 全自动执行默认自动验收评审任务；如果结果不合格，请用上面的退回/阻塞/改派纠正。
- 任务行、成员卡、办公室 inspector、本地/外部 Agent 档案都显示当前任务和进度条。

### Boss Inbox 与文件

- 审批卡现在显示所属任务、提出人、发起时间和审批历史；**待处理 / 已处理 / 全部** 可切换。
- 决策类审批的选项以卡片展示，包含优点和风险；**查看任务** 可直接跳回对应任务。
- 文件页可以继续上传文件；每个文件和预览弹窗都有原文件下载链接。
- 概览底部还提供 **复制任务**、**归档 / 取消归档** 和 **删除任务**；归档任务只在「已归档」筛选里显示，删除会二次确认并移除任务群、附件和审批记录。

## 6. 完成后开启下一轮

任务 100% 完成后，右侧概览不再误报「有 Agent 空闲」，而是：

> **本轮已完成 · 全员收尾**

下一步动作：

- **开启下一轮**：创建新任务，复用当前团队，携带上一轮交付物、决策、汇报和风险作为上下文；如果上一轮是自动执行且 AI 可用，新任务会自动开始。
- **查看复盘**：打开评估页。
- **查看计划**：查看所有任务和汇报。

标题会自动递增，例如 `AI电商运营 · 第 2 轮`。  
每一轮都会保留 `previousMissionId`，形成任务链。

---

## 7. 办公室动画与任务联动

- 工作/评审中的角色脚下有任务进度条，团队卡右侧显示当前任务百分比。
- 打开的任务/角色抽屉会跟随模拟实时刷新，并保留滚动位置和焦点。
- 空闲、聊天、评审有不同动画；暂停时办公室动画冻结，TEAM 和 HUD 显示 PAUSED。
- 任务完成后的庆祝是一次性动画，3 个 tick 后回到日常活动，不会永久定格。
- 任务 24 tick 无进展会被看门狗重新指派或放回看板。
- 完成横幅独立于缩放舞台，显示真实发布门禁结果；**新一轮** 重置场景，**查看审计** 打开缺口列表。

## 8. 工具、MCP 与升级

设置中心新增 **显示密度**：舒适模式在桌面放大任务、汇报和审批正文，紧凑模式一屏显示更多行。选择会保存在本机。

**工具** 面板包含：

- AI 模型服务 / 3 步接入 AI
- MCP 部署
- 演示与预设开关
- 自动检查更新
- 手动升级包
- 版本与回滚

MCP 可以把 Agent Office 作为本地 MCP 服务接入 Claude Code、Codex 或其他客户端；外部 Agent 可以领取任务、提交汇报和发消息。

## 9. 常见问题

**关闭演示后找不到外部 Agent？**  
先点「接入外部 Agent」，或确认 bridge 正在运行：`curl http://127.0.0.1:8787/health`。

**AI 显示不可用？**  
工具 → AI 模型服务 → 3 步接入，测试通过后才会启用。检查 API Key、接口地址或本地网关。

**任务完成后没有下一步？**  
打开已完成任务，顶部命令条或右侧 NEXT ROUND 卡片点「开启下一轮」。

**动画停了？**  
确认右上角是「暂停」而不是「继续」；任务完成后角色会继续日常活动。也可以点 SHIPPED 横幅的「新一轮」。

**页面还是旧版 / 左侧导航变成竖排文字？**
这通常不是前端样式 bug，而是 AgentOffice.app 运行的本地副本 `$HOME/agent-office` 缺少新 CSS 或仍是旧版本。开发目录同步后执行 `scripts/sync-local.sh`，再按 `Cmd+R` 刷新；必要时重启 bridge。检查 `http://127.0.0.1:5173/features.css` 应返回 200。若浏览器仍显示旧界面，按 `Cmd+Shift+R` 强制刷新；`serve.py` 已改为 no-store。
