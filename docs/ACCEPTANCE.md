## 9.8 关闭计划：卡口、责任和验收

> 9.8 不是“再改一次 UI”能得到的分数。下面把剩余项拆成三类；只有全部关闭并通过独立评审，才把对应维度写成 9.8。

| 项目 | 当前 | 卡口类型 | 需要谁 | 可验收的完成标准 |
|---|---|---|---|---|
| 公钥 / 第三方身份 | HMAC 共享密钥已实现，公钥未做 | 决策 + 依赖 | 你决定是否要求真实身份；授权引入 crypto 依赖并让外部 Agent 持有私钥 | Agent 私钥签名、桥接只存公钥、离线可验证、无共享密钥 |
| Windows 执行沙箱 | 明确 unavailable | 环境 | 一台 Windows 测试机，或可用的 Windows CI runner | Windows 上真实执行测试并通过隔离用例；不可用则明确拒绝 |
| Linux bubblewrap 实机 | 预检 + CI job 已写，未在本机跑 | 环境 | 推送分支跑 GitHub Actions，或提供 Linux 机器 | Linux 上 execution 测试实际通过，而不是 skip |
| 远程多租户 / 身份 | loopback + 可选 token/TLS，无用户体系 | 产品决策 | 你确定是否要多人/远程；提供域名、TLS、身份提供方 | 登录、租户隔离、审计、权限、远程浏览器可用 |
| Node / pytest 实跑 | 代码路径存在，本机无 Node/pytest | 环境 | 安装 Node（>=18）和 pytest，或 CI 中实跑 | 两种 runner 在沙箱内真实通过 |
| 流式聊天 / 分支 | 未做 | 纯工程 | 不需要你 | 流式增量、停止、重试、编辑/分支、断线恢复与测试 |
| 持久队列 / checkpoint | 重启恢复已做，队列未做 | 纯工程 | 不需要你 | 崩溃后续跑、幂等、去重、可观测、故障注入测试 |
| bridge 拆分 / 类型检查 | 单文件约 5.7k 行 | 纯工程 | 不需要你 | 模块边界、类型/JSDoc、回归和迁移文档 |
| 可访问性 / 负载 / 安全审计 | 基础键盘/焦点，未做专项 | 工程 + 外部评审 | 需要独立评审或用户验收 | 键盘全流程、屏幕阅读器、压测、渗透/威胁复核 |
| 价格自动更新 | 用户价格表已做，自动抓取未做 | 数据源 | 你提供价格来源/API，或授权联网抓取 | 可追溯来源、更新时间、失败回退，不猜价 |
| 独立模型评测 | 确定性 Evals 已有，模型评审未做 | 外部服务 | 你指定评测模型/预算 | 独立模型复核事实/证据，和自评分开记录 |

### 还需要几次

- **代码型（不依赖你）**：流式、持久队列/checkpoint、bridge 拆分/类型、可访问性与故障注入，预计 **1–2 个迭代**。
- **平台型（依赖环境/决策）**：公钥身份、Windows/Linux 实机、远程多租户，预计 **1–2 个迭代**，前提是环境和授权到位。
- **验收型**：独立评审、负载/安全审计、真实任务回归，预计 **1 个迭代**。
- 合计 **至少 3–4 个有验收标准的迭代**；如果 9.8 只要求本地单用户控制台，范围可以缩短，但不能同时声称生产多租户/公钥身份 9.8。

### 你可以直接辅助的事项

1. **冻结 9.8 范围**：本地单用户，还是包含远程多租户/Windows/公钥身份？范围不冻结，清单会一直增长。
2. **提供环境**：Windows、Linux 或 GitHub Actions 推送权限；这是跨平台验证的硬卡口。
3. **决定信任模型**：继续 HMAC，还是引入公钥/身份提供方；后者需要依赖和外部 Agent 配合。
4. **提供真实数据**：模型价格表/价格来源、2–3 个真实任务场景、外部 Agent 签名配置。
5. **验收反馈**：按“能完成什么、失败在哪、证据在哪”给出真实使用反馈，而不是只看界面。

## 1.27.0 验收证据

### 成本表与 MCP 签名（1.27.0）

- **价格表**：AI 接入向导新增每个 Provider 的可选输入/输出价格（每 1M tokens）与币种，写入 `providers.json`；真实响应后按真实 token 计算 `cost`，不猜测、不把未配置当免费。
- **成本可见**：模型调用台账新增成本统计、逐行成本和详情；Mission Eval 显示模型总成本、每个 Agent 的实际成本、未定价调用显示 `—`；混合币种显示 `MIXED`。
- **MCP 请求签名**：外部 Agent 创建/领取时拿到一次性 32 字节签名密钥，可用 `X-Agent-Timestamp` + `X-Agent-Signature` 对完整 JSON-RPC body 做 HMAC-SHA256；有效签名让证据回执记录 `identityBasis: agent-hmac`、`identityVerified: true`，缺失仍回退自报，签名错误/过期/重放直接拒绝。
- **密钥与回滚**：签名密钥不进入 `public_agent`、migration snapshot、浏览器存储或导出；`bridge-state.json`、`providers.json`、`evidence.json`、`evidence.key`、`evidence.anchor` 均按 `0600` 写入；支持 `POST /agents/<id>/signing-key` 轮换，UI 外部 Agent 行提供 ⚿ 生成按钮，密钥只显示一次。证据锚点能发现单独回滚 `evidence.json`，同时回滚证据与锚点仍无法防止。
- **执行预检**：Linux bubblewrap 增加真实 preflight；无法创建用户命名空间时返回 `unavailable`，不伪装成测试失败或降级执行。
- **重启恢复**：bridge 启动时把仍为 running/queued 的 autoRun/discussion 标为 interrupted，避免界面永久卡在进行中；不会盲目重跑已花 token 的模型任务。
- **真实闭环验证**：在临时状态副本中用真实 Anthropic 适配器跑了一个任务，512/5165 tokens、10 个交付文件、静态验证通过、证据回执有效、成本按验证价格表算出 0.010842 USD；按 DeepSeek Flash 官方价重算为 0.0031758 USD（周六 off-peak）/ 0.0063516 USD（peak，均按 cache miss）；沙箱 pytest 真实执行 6 项（3 通过/3 失败），失败确认为模型生成测试缺陷，任务未被假完成。详见 [VALIDATION_1.27](VALIDATION_1.27.md)。
- **CI 实测**：GitHub Actions 全绿——完整 Python 129 项、Linux bubblewrap 19 项（含 Node `node --test`，`/tmp` 只读）、Windows 兼容 job、浏览器 smoke；Linux 实跑发现并修复了 unittest 绝对路径、带连字符工作区名和 bwrap `/tmp` 可写三个真实问题。
- **验收**：Python **129** 项（本机 1 项 Node 跳过；Linux CI 已实跑 Node）、`dev-missions` **134** 项、`dev-usage` 成本检查、`dev-ai-setup` 价格字段、`dev-external` 签名入口、28 个浏览器页通过；共享 bridge 的页面改为串行，避免并行计数竞态。
- **仍不声称**：HMAC 不是公钥/真实身份；锚点不能防止证据文件与锚点一起回滚，未做 Windows 沙箱、模型价格自动更新、多租户和 bridge 拆分。9.8 仍是目标。

## 1.26.0 验收证据

### 通用执行器与证据回执（1.26.0）

- **执行后端**：`execution.py` 重写为后端强制模式。macOS 使用 `sandbox-exec`（已实测），Linux 使用 `bubblewrap`（已实现，需内核允许非特权 user namespace；本机未实机验证），Windows/无后端直接返回 `unavailable`，绝不降级为无沙箱执行。

- **MCP 交付**：新增 `agent_office_upload_deliverable`，外部 Agent 可上传文本交付物，并在 `agent_office_report_task` 中带 `artifactIds`；回执会哈希这些文件。来源标为 `external-agent`，`identityBasis: mcp-header`、`identityVerified: false`。
- **UI**：任务卡新增证据回执面板（状态、序号、来源、payload hash、验证/导出 JSON）、测试运行器/沙箱/命令元信息、自定义测试命令输入。验证结果和真实文件状态分开显示，不把“链上有效”写成“外部身份已验证”。

- **仍不声称**：Linux bubblewrap 尚未在本机实机执行；Windows 无后端；外部 Agent 身份签名、成本表、多租户和 bridge 拆分仍未完成。9.8 仍是目标，不是当前自评。
