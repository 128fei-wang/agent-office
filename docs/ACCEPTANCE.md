## 1.22.0 验收证据

### Token 预估、上下文洞察与模型调用（1.22.0）

- **不设 Token 上限**：新建任务表单移除 Token 上限；`tokenBudget` 固定为 0，自动执行不再因预算停止；每任务输入/输出预估仍然保留。
- **Context Insight**：任务评估页显示上下文来源（需求/验收、文件、记忆、历史汇报、决策）的字符与 token 估算，以及预估输入/输出/总计和实际调用输入/输出/平均延迟。
- **模型调用台账**：讨论、任务、交付物、聊天调用记录 Provider、模型、Mission/Task/Agent、上下文 chars/tokens、输入/输出、延迟、状态与错误；历史 usage 一次性回填。
- **查询 UI**：全局「模型调用」面板支持 Mission/用途筛选、搜索、统计卡、行详情；Eval 页可直接打开当前任务的调用明细。
- **验收**：`dev-usage.html` 16 项，`dev-missions.html` 114 项，Python 70 项；28 个浏览器页面全部通过。

## 1.21.1 验收证据

### 可用交付物（1.21.1）

- **占位交付物不再通过**：`已完成任务并提交交付物` 等短句会被质量门禁拒绝；任务不会被标记 done。
- **二次生成**：模型首轮 JSON 缺少交付物或输出被截断时，bridge 会单独请求完整交付物；仍不可用则保留任务并报错。
- **文件交付**：支持 JSON `files` 与 `file:path` 围栏，任务可产出代码、测试、发布脚本和 Markdown 报告；任务卡显示文件与大小。
- **重新交付**：任务卡提供重新交付按钮；文件页提供带 MANIFEST 的 ZIP 下载。
- **实测**：对用户当前「电商ai助手系统开发」任务重新交付了 7 个占位任务，生成 60 个文件（含实现代码、验收测试、发布/回滚脚本、风险预检和决策台账），任务恢复 done；旧的 36 字节占位文件被替换。
- **回归**：`test_mission_autorun_rejects_placeholder_deliverable` 验证占位交付物会让自动执行报错而不是假完成；Python 70 项、27 个浏览器页面全部通过。

### 安装版亲测（2026-11-27）

- 实测对象是 `AgentOffice.app` 实际加载的 `$HOME/agent-office`，不是开发仓库：`/health` 返回 1.22.0，静态资源带 `v=1.22.0` 且 `Cache-Control: no-store`。
- 真实模式：关闭演示后办公室显示 5 个外部 Agent 像素角色；`dev-demo-mode.html` 的 67 项检查全部 PASS。
- 真实任务联动：通过本机 bridge 新建临时任务并启动自动执行，Codex 角色在 415ms 内进入工作态，显示「需求边界与验收」任务气泡、进度条和 `workType` 工作动画；4 个空闲角色在 4.6 秒内移动到新工位；页面没有 `sim-paused` 冻结；停止并删除临时任务后，用户原有任务和 5 个外部 Agent 均保留（验收过程未改写真实任务内容）。
- 真实任务群聊：自动执行状态为 `running` 时在任务群发消息，输入态出现；收到 Codex 回复「当前进度：测试说明已进入准备阶段…」后输入态清除，随后临时任务被清理。任务群里的自动执行汇报不再误清输入态。

- 自动执行期间的群聊：新增回归测试覆盖“任务自动执行中，老板在任务群发消息仍会收到 Agent 回复”；任务群里的执行汇报不会再误清「Agent 正在输入…」，只有真正的聊天回复才结束输入态，避免旧逻辑再次静默丢弃群聊或过早收起输入提示。

### 真实业务与演示页面对齐

- 真实模式保留办公室舞台和动画，不再显示“全部暂停”的死界面。
- 外部 Agent 会显示在办公室工位上，带品牌 Logo、在线状态和悬浮动画；点击打开 Agent 档案。
- 顶部统计切换为真实指标：完成/任务、进行中、待审批、在线 Agent。
- 团队士气按“40 基础分 + 在线率 25% + 任务完成度 35% + 活跃任务 10%”计算，不再显示 “—”。
- REAL OPS 右栏改为真实任务活动流，显示状态、进度、当前任务和待审批。
- REAL OPS 面板和舞台提示均可关闭；顶部保留真实模式面板、任务中心、恢复演示和审批入口。

### 三项差距

1. **UI 字号与密度**：设置中心新增显示密度；舒适模式在桌面增大任务、汇报、审批正文并提高行高，紧凑模式保留更多行。
2. **规模化功能**：
   - 定时执行：任务可设置开始时间，bridge 调度线程到点自动开始；
   - 任务生命周期：归档/取消归档/复制/导出/删除；
   - 批量任务：勾选任务后批量接受评审或标记阻塞；
   - 批量审批：花费/登录/授权审批批量通过或拒绝；
   - Agent 健康：外部 Agent 档案可测试心跳。
3. **动画性能**：看板用任务签名跳过未变化重建；`dev-performance.html` 对 72 个任务验证看板/花名册渲染和重复渲染跳过。

## 部署验收

AgentOffice.app 实际运行的是 `$HOME/agent-office`，不是开发仓库。每次验收必须先同步安装副本：

```bash
scripts/sync-local.sh
```

然后刷新窗口，并确认 `http://127.0.0.1:5173/features.css` 与 `chat-v2.css` 均返回 200。`dev-features.html` 现在会检查左侧导航的真实宽度、圆角和标签是否水平，防止“仓库正常、安装版缺 CSS”的情况再次漏检。
