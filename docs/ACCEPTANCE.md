## 1.18 验收证据

### 真实动画验收（1.18.3）

- 关闭演示后，5 个外部 Agent 以像素角色出现在办公室，不再只显示 Logo 卡片。
- 当前执行真实任务的 Agent：高亮、工作摆动动画、任务气泡、任务进度条；点击打开档案。
- 其余 Agent 在工位/休息区之间行走；离线只降低亮度，不再让整个办公室静止。
- 外部 Agent 列表刷新会立即重建办公室角色，不必等下一轮任务轮询。
- CSS/JS 带版本查询参数，`serve.py` 返回 `Cache-Control: no-store`，避免旧缓存导致“看起来没修”。

### 真实业务与演示页面对齐

- 真实模式保留办公室舞台和动画，不再显示“全部暂停”的死界面。
- 外部 Agent 会显示在办公室工位上，带品牌 Logo、在线状态和悬浮动画；点击打开 Agent 档案。
- 顶部统计切换为真实指标：完成/任务、进行中、待审批、在线 Agent。
- 团队士气按“40 基础分 + 在线率 25% + 任务完成度 35% + 活跃任务 10%”计算，不再显示 “—”。
- REAL OPS 右栏改为真实任务活动流，显示状态、进度、当前任务和待审批。
- REAL OPS 面板和舞台提示均可关闭；顶部保留真实模式面板、任务中心、恢复演示和审批入口。

### 三项差距

1. **UI 字号与密度**：设置中心新增显示密度；舒适模式在桌面增大任务、汇报、审批正文并提高行高，紧凑模式保留更多行。
2. **规模化功能**：
   - 定时执行：任务可设置开始时间，bridge 调度线程到点自动开始；
   - 任务生命周期：归档/取消归档/复制/导出/删除；
   - 批量任务：勾选任务后批量接受评审或标记阻塞；
   - 批量审批：花费/登录/授权审批批量通过或拒绝；
   - Agent 健康：外部 Agent 档案可测试心跳。
3. **动画性能**：看板用任务签名跳过未变化重建；`dev-performance.html` 对 72 个任务验证看板/花名册渲染和重复渲染跳过。

## 非阻塞边缘增强

以下不影响 9.8 验收，但可作为后续方向：

- 多用户/远程 bridge 的鉴权与审计。
- 插件市场或更完整的 MCP 工具目录。
- 跨实例 Agent Registry 与负载均衡。
- 原生移动端封装、离线包与多语言扩展。

## 部署验收

AgentOffice.app 实际运行的是 `/Users/hashmai/agent-office`，不是开发仓库。每次验收必须先同步安装副本：

```bash
scripts/sync-local.sh
```

然后刷新窗口，并确认 `http://127.0.0.1:5173/features.css` 返回 200。`dev-features.html` 现在会检查左侧导航的真实宽度、圆角和标签是否水平，防止“仓库正常、安装版缺 CSS”的情况再次漏检。
