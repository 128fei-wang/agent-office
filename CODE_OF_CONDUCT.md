# Code of Conduct

## Our pledge

We want this project to be a place where people can learn, build and disagree about technical decisions without harassment or personal attacks.

## Expected behavior

- Be direct about code and ideas; be respectful to people.
- Assume good intent, but ask for evidence when behavior or claims are unclear.
- Give actionable review comments and explain the trade-off.
- Respect privacy: do not publish another person's logs, keys, endpoints or identity without consent.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized attention, deliberate intimidation, and publishing private credentials or conversations.

## Scope

This applies in repository issues, pull requests, discussions and any project-run space.

## Enforcement

Report concerns to the maintainers through the repository's private security/contact channel. Maintainers may edit or remove content and may temporarily or permanently ban contributors for behavior they judge harmful. Reports will be handled as confidentially as practical.

This is a lightweight code of conduct adapted for a small open-source project; the Contributor Covenant is a good reference if the project grows.
